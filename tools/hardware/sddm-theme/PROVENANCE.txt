Original BSD-2-Clause greeter. It is not a derivative of SDDM's bundled
Main.qml. Authentication is only sddm.login(); passwords are not logged.
BatteryStatus.qml reads a world-readable ACPI snapshot written by
publish-battery.sh (sysctl hw.acpi.battery.life / hw.acpi.acline). A missing
file hides the indicator. No Plasma import and no extra battery service.

FreeBSD-logo-light.png is the project wordmark from
https://www.freebsd.org/images/FreeBSD-logo-light.png (570x164 RGBA).
