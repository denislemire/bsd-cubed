Local changes: explicit h:mm AP time, yyyy-MM-dd date, removed layout label/selector and repaired tab order, optional battery model loader. November 8 layout follows the Ubuntu stick greeter: dimmed full-screen background, clock and date at the top, the user prompt in the center, and session, battery, and power controls along the bottom. The accent is FreeBSD red rather than Ubuntu orange. Existing SDDM embedded image resources are referenced, not copied. BatteryStatus.qml is original BSD-2-Clause code using the already installed KDE battery API. The loader isolates a missing optional module from the login form. No passwords are logged, stored or handled outside SDDM's existing login call.
